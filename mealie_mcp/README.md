# Mealie MCP Server (Home Assistant app)

Connect AI assistants (Claude, Home Assistant Assist, Claude Code and any MCP
client) to your [Mealie](https://mealie.io) recipe manager. They can search
and edit recipes, plan meals, and manage shopping lists.

- Works with Mealie running as another app on the same Home Assistant, or anywhere on your network
- Streamable HTTP endpoint on port 8099 (`/mcp`) with bearer-token protection
- amd64 and aarch64

Open the **Documentation** tab for step-by-step setup, including connecting
Claude Desktop and Claude custom connectors.
